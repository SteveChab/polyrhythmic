The grid

Swiss designers built page grids on these ratios in the 1950s.

Karl Gerstner pushed it further. His grid for Capital magazine has 58 units, so one page divides cleanly into 1, 2, 3, 4, 5 or 6 columns: several rhythms on one page. A 12-column web grid does the same with halves, thirds and quarters.
